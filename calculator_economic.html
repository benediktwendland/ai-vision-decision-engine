Dynamic Capital Calculation: Net Present Value (NPV)

Unlike static payback methods, the Net Present Value method accounts for the time-value of capital. Each yearly net cash flow (R_t) is discounted back to present value using the interest rate (i):
NPV = −I₀ + ∑ [ R_t / (1 + i)^t ]
